# Lesson 4 - Digital Inputs

## Component List

1. (1) x Elegoo UNO
2. (1) x 830 Tie-points Breadboard
3. (1) x 5mm red LED
4. (1) x 220 Ω resistor
5. (2) x push switches
6. (7) x M-M wires (Male to Male jumper wires)

The lesson introduces switches, as well as INPUT setups.
We also take a look at if statements to check if the switch is LOW => ledPin = HIGH (lighting up).
