# Lesson 17 - water-level-detector

## Components

1. (1) x Elegoo Uno R3
2. (3) x F-M wires (Female to Male DuPont wires)
3. (1) x Water lever detection sensor module

The lesson was about the sensor module and how it works. It quite a simple connection, between 5V, GND and any analog pin. Was terrified to place it into water to measure.
