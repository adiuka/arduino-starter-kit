# lesson 22 - eight-led

## Components
1. (1) x Elegoo Uno R3
2. (1) x 830 tie-points breadboard
3. (8) x leds
4. (8) x 220 ohm resistors
5. (1) x 74hc595 IC
6. (18) x M-M wires (Male to Male jumper wires)

Learned how to reduce the number of pins required when wiring multiple leds. Also practiced connecting much more components.
