# lesson 18 - real-time-clock-module

## Components
1. (1) x Elegoo Uno R3
2. (1) x DS1307 RTC module
3. (4) x F-M wires (Female to Male DuPont wires)

Learned a bit about the setting the real time clock module, by taking the time from my computers DATE and TIME objects. What was not stated in the lesson, is that once you set the date and time, you must comment out that code so it does not reset on reconnection every time.
