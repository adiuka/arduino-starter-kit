# lesson 21 - lcd-display

## Components
1. (1) x Elegoo Uno R3
2. (1) x LCD1602 module
3. (1) x Potentiometer (10k)
4. (1) x 830 tie-points Breadboard
5. (16) x M-M wires (Male to Male jumper wires)

Learned to connect and program the lcd display module to display text on setup and seconds on loop. The main challenge here was the wiring diagram. I accidentally connected the Read and Write pin to 5V instead of GND, which made it not work and bug out.
