# stepper-motor

## Components 

1. (1) x Elegoo Uno R3
2. (1) x 830 tie-points breadboard
3. (1) x ULN2003 stepper motor driver module
4. (1) x Stepper motor
5. (1) x 9V1A Adapter
6. (1) x Power supply module
7. (6) x F-M wires (Female to Male DuPont wires)
8. (1) x M-M wire (Male to Male jumper wire)

Learned how to use pulsating frequencies to move the stepper-motor. Again used the external power module.
