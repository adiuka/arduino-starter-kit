# Lesson 7 - tilt-ball-switch

## Components

1. (1) x Elegoo Uno R3
2. (1) x Tilt Ball switch
3. (2) x F-M wires (Female to Male DuPont wires)

The lesson involed loading connecting and coding a ball sensor, that turns on the pin 13 LED when the bal is LOW, and turns it off when it is HIGH.
