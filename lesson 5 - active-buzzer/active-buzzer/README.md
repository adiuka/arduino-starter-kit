# Lesson 5 - active-buzzer

## Components

1. (1) x Elegoo Uno R3
2. (1) x Active buzzer
3. (2) x F-M wires (Female to Male DuPont wires)

The lesson introduced male to female wires, as well as the Active buzzer component that is able to emit frequencies using for loops.
