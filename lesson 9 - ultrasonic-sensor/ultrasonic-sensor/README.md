# Lesson 9 - ultrasonic-sensor

## Components
1. (1) x Elegoo Uno R3
2. (1) x Ultrasonic sensor module
3. (4) x F-M wires (Female to Male DuPont wires)

The lesson introduced the SR04 library, that allows the ultrasonic sensor to calculate distance. Also used the monitor to debug.
