# Lesson 16 - pir-sensor

## Components

1. (1) x Elegoo Uno R3
2. (1) x HC-SR501 PIR motion sensor
3. (3) x F-M wires (Female to Male DuPont wires)

The lesson was about the ir-detection-module and the quirks it posseses. The module detects changes in infra red light in a 110 degree radius around it's lenses. One of the quirks is that the sensor has a built in 3 second cooldown.
