# Lesson 8 - servo

## Components

1. (1) x Elegoo Uno R3
2. (1) x Servo (SG90)
3. (3) x M-M wires (Male to Male jumper wires)

The lesson was about setting classes and using the Servo class to set up a loop, that moves the servo arm towards different degrees.
