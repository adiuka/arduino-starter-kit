# Lesson 11 - temperature-and-humidity

## Components
1. (1) x Elegoo Uno R3
2. (1) x DHT11 Temperature and Humidity module
3. (4) x F-M wires (Female to Male DuPont wires)

Learned to work with the temperature and humidity module in a non-blocking way. Meaning we do not stop our program using delays, and instead using a helper function to check whether enough time has passed since the last check, which allows the sensory module to keep doing it's thing.
