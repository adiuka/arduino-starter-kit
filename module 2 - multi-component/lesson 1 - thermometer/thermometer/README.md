# lesson 1 - thermometer

## components

1. (1) x Elegoo Uno R3
2. (1) x LCD1602 Module
3. (1) x 10k ohm resistor
4. (1) x Thermistor
5. (1) x Potentiometer
6. (1) x 830 tie-points Breadboard
7. (18) x M-M wires (Male to Male jumper wires)

Learned how to connect and display temperature readings on an lcd display. Was quite surprised on the tiny size of the temperature sensor.
