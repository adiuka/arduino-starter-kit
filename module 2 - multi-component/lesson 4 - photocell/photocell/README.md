# lesson 4 - photocell

## components

1. (1) x Elegoo Uno R3
2. (1) x 830 tie-points breadboard
3. (8) x leds
4. (8) x 220 ohm resistors
5. (1) x 1k ohm resistor
6. (1) x 74hc595 IC
7. (1) x Photoresistor (Photocell)
8. (16) x M-M wires (Male to Male jumper wires)

Expanded on the 8 LED lesson with the 74hc595 IC chip. This time, we added a light sensor, that changes the amount of leds turned on based on the brightness of the room. A brightness sensor in the making right here for that Thief cossplay.
