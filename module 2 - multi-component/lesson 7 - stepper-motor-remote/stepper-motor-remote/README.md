# lesson 7 - stepper-motor-remote

## components

1. (1) x Elegoo Uno R3
2. (1) x 830 tie-points breadboard
3. (1) x IR receiver module
4. (1) x IR remote
5. (1) x ULN2003 stepper motor driver module
6. (1) x Stepper motor
7. (1) x Power supply module
8. (1) x 9V1A Adapter
9. (9) x F-M wires (Female to Male DuPont wires)
10. (1) x M-M wire (Male to Male jumper wire)

Learned how to wire and use the stepper motor together with the IR receiver and Remote.
