# lesson 2 - segment-display

## components

1. (1) x Elegoo Uno R3
2. (1) x 830 tie-points breadboard
3. (1) x 74HC595 IC
4. (1) x 1 Digit 7-Segment Display
5. (8) x 220 Ωresistors
6. (26) x M-M wires (Male to Male jumper wires)

Learned how to use the 74HC595 chip together with the 7 segment display and only 3 pins to display all I need. The wiring scheme was quite difficult this time, requiring a bit of cable management.
