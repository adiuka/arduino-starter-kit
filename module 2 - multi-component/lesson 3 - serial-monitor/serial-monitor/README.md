# lesson 3 - serial-monitor

## components

1. (1) x Elegoo Uno R3
2. (1) x 830 tie-points breadboard
3. (8) x leds
4. (8) x 220 ohm resistors
5. (1) x 74hc595 IC
6. (14) x M-M wires (Male to Male jumper wires)

The lesson builds on module learning, specifically the 74hc595 IC chip and Serial Monitor. You can send data for the serial to listen to, which then can trigger functions or actions on the arduino board. In this case, turning on and shutting off leds.
