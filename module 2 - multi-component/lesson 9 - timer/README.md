# lesson 9 - timer

## components

1. (1) x Elegoo Uno R3
2. (1) x 830 breadboard
3. (1) X Active Buzzer
4. (1) x NPN transistor 8050
5. (3) x key
6. (1) x LED lamp
7. (5) x 220_resistance
8. (1) x 10k_resistance
9. (1) x 74HC595 IC
10. (1) x 4 Digit 7-Segment Display
11. (2) x M-F wires (Male to Female jumper wires)
12. (32) x M-M wires (Male to Male jumper wires)

Learned the complexities of using old libraries. Had to rewrite a library with AI to get the timer working, as the lesson did not really explain how interrupts work. Interrupts stop the execution of a program to run another function, while saving the spot where they left off and are very useful when trying not to lose inputs. 

The connecting work was also a huge hassle, and without a delimiter - very hard to debug. This made me order discreet wires.
