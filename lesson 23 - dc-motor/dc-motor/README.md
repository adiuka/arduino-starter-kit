# lesson 23 - dc-motor

## Components
1. (1) x Elegoo Uno R3
2. (1) x 830 tie-points breadboard
3. (1) x L293D IC
4. (1) x Fan blade and 3-6v motor
5. (5) x M-M wires (Male to Male jumper wires)
6. (1) x Power Supply Module
7. (1)x 9V1A adapter

Learned to work with the dc-motor component and the accompanying L293D that can control it. But most importantly learned to use an external power adaptor to provide more power that the Arduino board can manage sometimes. This is useful for components that need a bit more umpf.
