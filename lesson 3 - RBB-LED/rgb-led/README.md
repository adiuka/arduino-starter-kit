# RBG-LED

## Components
1. (1) x Elegoo Uno R3
2. (1) x 830 Tie Points Breadboard
3. (4) x M-M wires (Male to Male jumper wires)
4. (1) x RGB LED
5. (3) x 220 ohm resistors

Second assignment with connecting an RGB LED together with 3 resistors. Using loops and delays we are able to change the colors of the LED.
